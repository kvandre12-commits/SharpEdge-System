Architecture

Three pipeline layers. All processes automated via scheduled workflows with reproducible SQLite state.

01

Truth Layer

Raw market-data ingestion and normalization. Alpaca, FINRA, and FRED feeds land in one consistent store — with freshness gates and cache controls so routine runs skip network calls while state is fresh.

02

Feature Layer

Derived signals, regimes, and structural context. Liquidity and regime classification turn raw bars into the features the decision layer reasons over.

03

Decision Layer

Backtested rules, calibrated DTE selection, and trade plans. Every order is gated behind freshness, sample-size, and monitor checks before anything executes.

Built for discipline

Refuses bad trades

Blocking reasons are explicit — stale inputs, low samples, monitor holds. No silent overrides.

Reports per-regime expectancy

No single headline number. Performance is broken down by regime bucket at enforced minimum sample sizes.

Operator briefs

A thin compression layer over local artifacts: stand-down / monitor / review summaries, watchlists, and session reviews.

Reproducible state

SQLite-backed pipelines with state breadcrumbs — reruns are deterministic, not vibes.
